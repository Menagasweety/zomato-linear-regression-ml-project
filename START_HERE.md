# How to use this project

Open Jupyter Notebook in this folder.

Run the notebooks in this order:
1. 01_Data_Audit.ipynb
2. 02_Data_Cleaning.ipynb
3. 03_EDA.ipynb
4. 04_Feature_Engineering.ipynb
5. 05_Baseline_Model.ipynb
6. 06_Linear_Regression.ipynb
7. 07_Regularization_Evaluation.ipynb
8. 08_Final_Evaluation.ipynb

Run notebook 09 only if you want to understand classification and confusion matrices.

Do not skip the audit and EDA just to get to the model. The point of the project is to learn how the modeling decisions are justified by the data.
